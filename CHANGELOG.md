### Added
- 25/5/15-minute Pomodoro timer (focus / short break / long break)
- Start, pause, and reset controls
- Session counter with automatic long-break scheduling (every 4th focus session)
- Optional notification sound via the Web Audio API (no external audio file)
- Optional browser notifications when a session ends
- Clean, responsive, light/dark-aware design
- Preferences (sound, notifications, session count) persisted in localStorage
